Cookie & Local Storage Policy.

This draft describes known GlassChat website and desktop storage behavior. It is not a complete provider cookie notice or legal advice.

GlassChat website

The public site uses browser local storage under the key glasschat-site-theme to remember a visitor's dark/light theme choice. The site code does not currently use advertising analytics or set a tracking cookie. GitHub Pages may process request metadata to host and secure the site under GitHub's own policies; this draft does not describe every GitHub-side mechanism.

Email action pages

Verification and reset links carry a one-time token in the URL fragment. The fragment is not part of the HTTP request to GitHub Pages. After the visitor submits the form, the page removes the fragment from the visible URL and posts the token directly to the configured GlassChat API. The page does not save the token in local storage or send authentication cookies with that request.

GlassChat desktop client

The Electron client saves service settings in its per-user application data directory. It keeps session material in the main process and uses Electron's operating-system encrypted storage when available. The renderer does not receive the raw session token. The current Beta does not keep authoritative local-only conversation history; channel messages are stored centrally by the service as described in the Privacy Policy draft.

Cookies and service operation

The backend uses an HttpOnly session cookie for its authentication API. The desktop main process handles this session; the static website's email-action forms omit cookies and rely on a one-time token. The public site does not currently provide an authenticated account dashboard.

Owner review

Review this page against the final hosting configuration, the live backend and applicable Danish/EU requirements before public service launch. Update it if analytics, additional cookies, local storage, embedded content or account web sessions are added.
