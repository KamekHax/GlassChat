GlassChat 1.0.1 Windows Beta source candidate

Version 1.0.1 · source build 20261031.3 · build date 2026-10-31. This is not a Windows installer, GitHub Release or public download.

Packaging: the project retains per-user NSIS and portable Windows x64 configuration. Earlier 1.0.1 binaries are unsigned local candidates and do not contain this source build.

Account mail: the temporary Render deployment has a Gmail API Testing credential. The owner received a one-off test email. The refresh token expires after seven days; registration and password-reset flows have not been tested end to end.

Regression checks: the repository's seven automated tests passed in the sandbox on 2026-10-31, including account/session lifecycle, CORS origin restriction, community membership/realtime messages, Gmail API request construction, and legacy server history. This is not a live Gmail, PostgreSQL, Render or native Windows test.

Still open: end-to-end account/email tests, durable email authorization, native Windows lifecycle testing, release signing, automatic updates, local-first history and end-to-end encryption are not complete. The API and Neon schema are deployed only as a temporary Beta test.
