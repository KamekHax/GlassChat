GlassChat is a desktop text-chat Beta with its own account system and a Liquid Glass-inspired interface. Today, the implemented slice is deliberately small: one community, one general channel, and the basics of live text chat.

These are capabilities present in the application source and tests. They are not a claim that a public hosted service is available.

#

Commons · #general

The Beta seeds one community and one general text channel. Member-scoped history, live messages, presence and typing are implemented in the backend/client slice. Channel text is stored centrally as readable plaintext at the application layer.

G

GlassChat-owned accounts

Email/password registration, Argon2id password hashing, verification and recovery tokens, revocable SQL sessions and server-side membership checks are implemented in source. There is no public account service yet.

A roadmap without guesswork

Direct messages, profiles, uploads, voice and video are not implemented. See what is delivered, still gated, and only planned.

Product vision

The direction GlassChat is aiming for.

“Discord functionality. Liquid Glass aesthetics. Lightweight performance. Freedom without Nitro.”

That line is an aspiration, not a description of features already shipped or a measured performance benchmark. The current Beta is a single text channel. There is no GlassChat paid tier in this candidate.

Important to know

Private conversations are not ready.

The current Beta is not local-first and does not use end-to-end encryption. Channel message text is stored centrally in PostgreSQL in plaintext at the application layer. Do not use this build for private or sensitive conversations.

Not available today

No DMs, voice, video or screen sharing

GlassChat currently has one seeded text community. Social features and real-time media remain roadmap items and will not be described as working until they are implemented and tested.
