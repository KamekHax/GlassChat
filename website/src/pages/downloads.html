Before installing

System and release status.

Version 1.0.1 · source build 20261031.3 is the current Beta candidate. It has not been published as a GitHub Release.

Supported Windows versions: none have passed native verification yet; Windows 10 and Windows 11 x64 are the intended targets. Install, upgrade, shortcut, data-preservation and uninstall behavior remains untested on native Windows.

System requirements: the current build targets x64 Windows. Minimum CPU, memory, disk-space and specific OS-build requirements have not been established or published.

Signature: the current candidate is unsigned. Windows SmartScreen may show a warning.

Updates: automatic updates are not enabled. Users will need to install a newer official release manually.

Service: the temporary Render Free API is live, but can sleep and currently uses a Gmail OAuth Testing credential that expires after seven days. The app account flows are not yet verified end to end. No installer is available yet.
