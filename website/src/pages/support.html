Help, not guesswork

Support and bug reporting.

GlassChat is an independent project. The public support contact for questions, privacy requests, security reports and legal correspondence is kamekfnbr@gmail.com.

Project support

Tell us what happened.

Before reporting a bug, check the current documentation and release status. The central chat service is not yet publicly deployed; login failures in local or unpublished candidates are expected.

Email GlassChat support

Open a public GitHub issue for a non-sensitive bug ↗

Include useful context

  • GlassChat version and build ID, from the About/footer or installer properties.
  • Windows version and whether you used setup or a portable build.
  • Steps to reproduce and the exact sanitized error message.
  • Whether the issue affects a published release or an unpublished development candidate.

Do not include passwords, session tokens, verification or reset tokens, private message content or database credentials.

Security issue? Do not post exploit details, credentials or sensitive user data in a public issue. Email kamekfnbr@gmail.com privately. Do not include access tokens or personal message contents in the first report.
